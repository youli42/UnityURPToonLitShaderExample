# Toon 学习指南（Unity 2022.3 URP）

本分支把原来的纯 shader 仓库升级成了一个可直接打开的 Unity 工程，**不含任何模型/贴图资产**，只用 Unity 内置图元演示赛璐璐（toon）着色，便于逐条对比参数效果。

- 引擎：`Unity 2022.3.42f1c1`（`ProjectSettings/ProjectVersion.txt` 已锁定）
- 管线：`URP 14.0.11`（编辑器内置包，无需联网拉取）
- 上游 shader：[ColinLeung-NiloCat/UnityURPToonLitShaderExample](https://github.com/ColinLeung-NiloCat/UnityURPToonLitShaderExample)，注释已汉化（英文原版在 `master` 分支）

## 打开工程

双击根目录 `open-unity.bat`（直连本机编辑器，不走 Hub），或在 Unity Hub 里 Add Project 选择本目录。
打开后菜单 `Toon Learning → Setup` 是全套一键脚本。

## 场景里每个图元在演示什么

| 物体 | 关键参数 | 现象 |
| --- | --- | --- |
| Sphere_HardEdge | `_CelShadeSoftness = 0.02` | 明暗一刀切，典型硬边赛璐璐 |
| Capsule_SoftEdge | `_CelShadeSoftness = 0.35` | 同一 MidPoint，分界变软 |
| Cylinder_LitArea | `_CelShadeMidPoint = -0.8` | 亮部面积更大（MidPoint 越负越亮） |
| Cube_Outline | `_OutlineWidth = 3` | 粗描边（法线外扩实现） |
| Ground | `_OutlineWidth = 0` | 地面不描边，避免接缝 |

运行后：`A` / `D` 旋转主光源看明暗分界移动，`O` 开关全场景描边做对比。

## 参数速查（材质面板顺序即 shader `Properties` 顺序）

- `_BaseColor` × `_BaseMap` → albedo。本工程用白底图 + 纯色，方便看清光照分层。
- `_CelShadeMidPoint` / `_CelShadeSoftness` → cel shade 分界位置与软硬（核心两参）。
- `_MainLightIgnoreCelShade` / `_AdditionalLightIgnoreCelShade` → 是否对某类光跳过 cel 分层。
- `_ReceiveShadowMappingAmount` / `_ShadowMapColor` → 阴影贴图强度与阴影染色（原神味道的关键）。
- `_IndirectLightMinColor` / `_IndirectLightMultiplier` / `_DirectLightMultiplier` → 间接光保底与直射光亮度。
- `_IsFace` → 面部/眼/口跳过 NoL 分层（模型阶段才需要，现留作接口）。
- `_OutlineWidth` / `_OutlineColor` / `_OutlineZOffset` → 描边粗细、颜色与防穿模偏移。
- `_UseAlphaClipping` / `_UseEmission` / `_UseOcclusion` → 透明裁剪、自发光、遮蔽贴图开关。

## 五个 Pass

`UniversalForwardOnly`（主输出）· `Outline`（法线外扩反向描边）· `ShadowCaster`（投影）·
`DepthOnly` · `DepthNormalsOnly`（后处理需要的深度/法线预通道）。
后四个只在 URP 真正需要时才渲染，改 shader 时不要误删标签。

## 学习路线建议

1. 先只改 `SimpleURPToonLitOutlineExample_LightingEquation.hlsl`：它一个文件几乎决定全部画面风格。
2. 再读 `..._Shared.hlsl` 理解 CBUFFER / SRP 合批 / 5 pass 的组织方式。
3. 想加"色阶数量"、"阴影边缘抗锯齿"、"区域阴影染色"等效果时，改上面两个文件即可，不用动主 `.shader`。

## 复现与验证

```
"C:\Program Files\Unity 2022.3.42f1c1\Editor\Unity.exe" -projectPath <本目录> -batchmode -quit ^
  -logFile <日志> -executeMethod ToonLearning.Editor.ToonProjectBootstrap.RebuildAndCapture
```
日志里 `[ToonDemo] 全黑像素占比` 是自检指标，正常应接近 0%。

### 注意：材质必须绑定 `_BaseMap`

`albedo = tex2D(_BaseMap) * _BaseColor`，脚本创建的材质若 `_BaseMap` 为空槽位，采样结果是黑色，
整个画面会变全黑（天空正常、几何体全黑）。本工程用 `Assets/Textures/White_1x1.png` 显式兜底。
